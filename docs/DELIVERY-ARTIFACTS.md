## Pull Request Description

### Summary

Implements the initial React finance dashboard application (Part 1 of the GitHub SDLC Lab).  
The application is demo-ready and CI-validated.

### What was added

#### Application scaffold
- **Vite 8 + React 18** project with ESM modules
- **ESLint v9** flat config — enforces react and react-hooks rules with zero warning tolerance
- **Vitest 5 + Testing Library** for unit and render tests

#### Data layer — `src/services/financeService.js`
- Calls the local Express proxy (`/api/quotes`, `/api/history/weekly`, `/api/history/quarterly`)
- Automatic **mock fallback** if the proxy is unreachable — tests and offline demos always work
- `normaliseForComparison()` utility — transforms absolute price series into index-100 rows for comparison charts
- Easy to extend: add a new company by editing one array (`COMPANIES`)

#### Backend proxy — `server/`
- Minimal **Express** server on `http://127.0.0.1:3001` (never binds to 0.0.0.0)
- Uses **yahoo-finance2 v4** (latest stable, zero CVEs)
- Ticker **allowlist** — only IBM, MSFT, ORCL, SAP, CRM are accepted
- All errors logged server-side; only generic messages reach the client

#### UI components
| Component | Description |
|---|---|
| `SummaryCard` | Current price, change, % change, volume with up/down colour coding |
| `ChartCard` | Multi-line Recharts line chart with loading skeleton and error state |
| `AreaChartCard` | Same shell as ChartCard but uses filled areas with gradient fills |
| `RankingCard` | Ranked list sorted by daily % change |

#### Dashboard page
- **Current Day** tab — 5 SummaryCards + RankingCard
- **Last 7 Days** tab — AreaChartCard (indexed to 100)
- **Last Quarter** tab — ChartCard (absolute price) + AreaChartCard (indexed) side-by-side
- Refresh button reloads all three data sources
- Full ARIA roles and labels for accessibility
